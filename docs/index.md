시간순 블로그가 아니라 **순서가 있는 정리본**이다. 앞 챕터가 뒤 챕터의 전제가 된다.

| 챕터 | 다루는 것 |
|---|---|
| [1. LLM 소개](01-intro.md) | LLM이 무엇이고 어떻게 동작하는가 |
| [2. 로컬 LLM](02-local-llm.md) | 내 컴퓨터에서 모델 돌리기 |
| [3. HuggingFace 모델 다운로드 & 추론](03-hf-inference.md) | `transformers`로 모델 받아서 추론하기 |

## 각 챕터 구성

모든 챕터가 같은 세 섹션으로 되어 있다.

- **한 줄 요약** — 목록만 훑을 때 여기만 읽는다
- **핵심** — 개념과 코드
- **헷갈렸던 것** — 막혔던 지점과 잘못 이해했던 것

세 번째가 이 정리본의 존재 이유다. 개념 설명은 검색하면 나오지만, *내가* 어디서 헷갈렸는지는 지금 적어두지 않으면 사라진다.
